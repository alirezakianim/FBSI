# Changelog

## [1.0.0] - 2026

First public release, accompanying Kianimoqadam & Schrader, CMAME 461 (2026) 119161.

- Python reference implementation (`python/fbsi`): FBSI, direct-numerical reference, PCM,
  isotropic and Gaussian kernels, virtual exterior cells for boundaries, small test meshes.
- Header-only C++17 implementation (`cpp/include/fbsi/fbsi.hpp`).
- Examples, test suites (pytest and ctest), method description and implementation guide.
